# Allow-list for everything AXYON publishes (#2532). Read by check-public-tree.sh,
# which ships with it in the public repo (scripts/) and runs there in CI and
# before every publish from the private repo.
#
# Sections:
#   [tree]     paths of the public git repository (axyon-lang/axyon-releases)
#   [archive]  members of a release archive, relative to its top directory
#              axyon-<version>-<triple>/
#   [assets]   files attached to a GitHub release
#   [content]  extended regexes that must not appear in any text file of the tree
#
# `+ GLOB` allows, `- GLOB` denies, `- GLOB unless GLOB` denies except where the
# second glob matches. A deny always wins over an allow, and every file must be
# allowed: a path matching no `+` rule fails. Globs: `*` and `?` stay inside one
# path component, `**/` spans any number of directories, `**` at the end matches
# everything below. Directories need no rule (only files and symlinks are checked).
#
# Never widen [tree] to compiler source, design docs, perf studies, dev-loop
# material or internal scripts. The private repo's copy is the source of truth.
